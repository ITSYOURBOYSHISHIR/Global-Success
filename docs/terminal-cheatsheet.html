Mac Terminal Cheat Sheet

Useful commands for your Thuldai website & everyday Mac work · August 2026

Navigate & folders

CommandWhat it doesExample
pwdPrint working directory — where you are nowpwd
cd PATHChange directory — go into a foldercd ~/Projects/NEPAL-AUSTRALIA/website
cd ..Go up one foldercd ..
cd ~Go to your home foldercd ~
lsList files in current folderls
ls -laList all files with details (size, dates, hidden)ls -la
mkdir NAMEMake directory — create foldermkdir assets
cp A BCopy file or foldercp index.html backup.html
mv A BMove or renamemv old.html new.html
rm FILERemove file (no Trash — be careful)rm temp.txt
open .Open current folder in Finderopen .
open FILEOpen file with default appopen index.html

~ = home folder · .. = parent folder · ./file = file in current folder

Read & search files

CommandWhat it doesExample
cat FILEPrint whole filecat readme.txt
head -n 20 FILEFirst 20 lineshead -n 20 index.html
tail -n 20 FILELast 20 linestail -n 20 server.log
less FILEScroll through file (q to quit)less style.css
grep "text" FILESearch for text in a filegrep "Thuldai" index.html
grep -r "text" .Search in all files under current foldergrep -r "localhost" .
find . -name "*.html"Find files by namefind . -name "*.html"

Local website (preview your site)

CommandWhat it doesExample
python3 -m http.server PORTStart a simple web server in current folderpython3 -m http.server 8081
curl URLTest a URL from Terminalcurl http://localhost:8081/index.html
curl -I URLShow headers only (check if server responds)curl -I http://localhost:8081/

Same Mac: http://localhost:8081/index.html · Phone (same Wi‑Fi): http://YOUR_IP:8081/index.html

Network & IP

CommandWhat it doesExample
ipconfig getifaddr en0Your Mac’s Wi‑Fi IP (for phone testing)ipconfig getifaddr en0
ifconfigAll network interfaces & IPsifconfig | grep "inet "
ping HOSTTest if something is reachableping google.com
ping -c 4 HOSTPing 4 times then stopping -c 4 192.168.1.1

en0 = usually Wi‑Fi · en1 = sometimes Ethernet

Ports & processes

CommandWhat it doesExample
lsof -nP -iTCP:8081 -sTCP:LISTENIs anything listening on port 8081?lsof -nP -iTCP:8081 -sTCP:LISTEN
kill PIDStop a process by IDkill 12345
kill -9 PIDForce stop a processkill -9 12345
ps aux | grep pythonFind Python processesps aux | grep python

Useful syntax symbols

SymbolMeaningExample
| (pipe)Send output into another commandls | grep html
>Save output to file (overwrite)ls > files.txt
>>Append output to fileecho hello >> log.txt
&&Run 2nd command only if 1st succeedscd website && python3 -m http.server 8081
;Run commands one after anothercd website; ls
#Comment (ignored)# this is a note
Ctrl+CStop running command (e.g. stop server)while server is running
Ctrl+LClear screen
↑ / ↓Previous / next command in history
